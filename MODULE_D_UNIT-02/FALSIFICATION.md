# MODULE D — FALSIFICATION CONDITIONS

Module D is considered **failed** if:

1. It does not exhibit memristive hysteresis in the *Physarum*-PEDOT:PSS
   bridge (Lissajous loop with characteristic pinching at increasing
   frequency, distinguishable from controls: PEDOT without *Physarum*, dead
   *Physarum*).
2. It does not generate a pure toroidal (anapole) moment with dipole
   suppression ≥ 15 dB (near-field vs far-field probe measurement).
3. It does not maintain *Physarum* biocompatibility for ≥ 3 months in field
   conditions (LDH viability + preserved rhythm of streaming and potentials).

**Note on condition 1:** failure weakens the morphological-memory claim
without killing the OECT function — the bridge still transduces continuously.
The document declares this explicitly before the data arrive.

Negative results are results. They will be published with the same DOI
discipline as positive ones.

## Data Quality / Limitations
- Values extracted from mobile screenshots; daily labels printed on charts; pulse dates carry ±1 day mapping uncertainty.
- Rolling 14-day windows: day-over-day deltas inside one window are not independent observations; overlapping windows are not summed or compared as growth.
- Unique visitors/cloners deduplicated per window (daily sums exceed window uniques); not additive across repositories.
- Coverage incomplete: 4 of 9 previously tracked repositories not supplied (TOKIO_DRIFT_44, LifeNode_2.5_Public, Cosmic_BioEngineering, LifeNode777 profile). Cross-ecosystem comparisons from prior session cannot be replicated.
- Self/author traffic present; bots, mirrors and automation not separable; unattributed fraction not quantifiable.
- Author statements (Module H work, README article, MetaContract post-commit silence) are author-supplied T1 evidence, not independently verified.
- LOG.txt provides Module H execution timeline but does not establish external fetch causality.
- Metric discipline: clones ≠ researchers; views ≠ readers; downloads ≠ users; traffic ≠ validation; commit ≠ result; reach ≠ acceptance.

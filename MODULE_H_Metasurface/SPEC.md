## 2. PHYSICS: CONVOLUTION WITHOUT A PROCESSOR

### 2.1 Wave convolution on a metasurface
In the spatial scheme, metasurface + propagation (or a 4f system) realizes a designed transfer function such that the output field is the convolution of the input field with kernel $G$:

$$E_{out}(x) = \int E_{in}(x')\, G(x - x')\, dx'$$

where $G$ is **the Green's function etched into the meta-atom layout** — the kernel being the soliton template (e.g., the Peregrine S2 profile as an amplitude–phase mask). The result is not a number: it is a continuous intensity at the probe point — **correlation as a field, not as a register**.

### 2.3 Carrier and envelope: ontological alignment with Module D

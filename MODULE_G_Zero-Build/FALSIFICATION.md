# MODULE G — FALSIFICATION CONDITIONS

Module G is considered **failed** if:

1. In blinded tests (n ≥ 100) a drop θ < 0.70 does not precede arrhythmia by ≥ 6 h.
2. Detection sensitivity falls below 60%.
3. The predictive power of θ can be fully replicated (p > 0.05) by standard point metrics (mean HR, peak amplitude) without phase-space reconstruction.

Negative results are results. They will be published with the same DOI discipline as positive ones.
